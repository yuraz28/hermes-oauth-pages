Privacy Policy

Hermes Agent — Google Workspace access · personal single-user client

This application is operated by and for one person — its owner, Yuri Zaretskiy (zaretskiy.y.a@gmail.com). It is installed locally on the owner's own computer. It has no other users, no servers of its own, and no data sharing with third parties.

1. What data is accessed

With the owner's explicit consent, and only for the owner's own Google account, the application may access:

  • Google Drive — file names, metadata and contents, to read, search, create and edit files;
  • Google Docs, Sheets, Slides, Forms — documents the owner opens, creates or edits;
  • Gmail — messages, threads and labels, to read, draft and send mail on the owner's instruction;
  • Google Calendar — events and calendars, to read and create events;
  • Google Tasks — task lists and tasks;
  • Google Contacts — contact names and addresses, for look-up;
  • Google Apps Script — script projects belonging to the owner;
  • Basic profile — name and email address, to identify the account.

2. How the data is used

Data is used solely to carry out actions the owner requests in a conversation with the agent: finding a file, summarising a document, drafting a reply, scheduling a meeting and similar tasks. The application does not build profiles, does not mine data, does not train models on it, and does not use it for advertising.

3. Where the data is stored

  • OAuth tokens are stored locally on the owner's computer in ~/.google_workspace_mcp/credentials/, readable only by the owner's operating-system account.
  • Documents and messages themselves remain in the owner's Google account. The application keeps no copy of them.
  • Conversation logs may be stored locally on the owner's computer for the owner's own reference.

4. Sharing

No data is sold, rented or shared with third parties. Content is transmitted only to the Google APIs the owner is acting upon, and — when the owner uses a language-model provider through the agent — the specific text needed to answer a request, subject to that provider's own terms. There is no analytics, tracking or advertising component.

5. Retention and deletion

Access tokens are refreshed until the owner revokes access. The owner can revoke the application's access at any time at myaccount.google.com/permissions; from that moment the stored tokens stop working. Local token files can be deleted at any time by removing the directory named above.

6. Security

Communication with Google uses HTTPS only. Tokens are stored with file permissions limited to the owner's user account. The application runs locally; there is no public endpoint holding user data.

7. Changes

This policy may be updated if the application's scope changes. The date below reflects the current version.
